## 1:00–4:00 正常演示：完整流程顺下来

| # | 操作 | 应出现的画面 |
|---|---|---|
| 4 | 点「运行」 | `Planner` 亮，拆 4 子任务，下发箭头指向四个下级 |
| 5 | 等 `Intel` 亮 | 弹出**三个情报源卡片**：卫星侦察(T2) / 公开网络(T1) / 敌台截获(T1·可疑) |
| 6 | 选「敌台截获」→ 切「采用(LEARN)」读 | Intel 节点**变橙**，水位 gauge 降（脏情报被吸收） |
| 7 | 采用后 Agent 写一条结论 | 写门 ALLOW，溯源链里**能看到投毒源的 chunk_id**（污染进了 lineage） |
| 8 | 同一源 → 切「查阅(CONSULT)」读 | 水位**不动**，内容被 HIDE 遮蔽成 `#var#`，弹 `READ_HIDE` |
| 9 | 查阅后 Agent 试图基于它写结论 | 写门 **DENY**，弹「CONSULT 禁写回 · I14」，结论写不出 |
| 10 | 等 `Log` 亮 | 查内网雷达日志，T3 可信，节点**绿** |
| 11 | 等 `Analyst` 亮 | 融合多源（取最脏一环）+ 推理衰减 → 结论 **T1**，节点橙 |
| 12 | 弹「背书确认」→ 选 L3 → 解密看明文 → 批准 | 明文出 → Analyst **橙变绿**（T1→T3） |
| 13 | 等 `Executor` 亮 | 高危处置动作 → 弹「HITL 确认」→ 批准 → 动作下发 |
| 14 | 等 `Auditor` 亮 | 旁路审计全链，无越权 |
| 15 | 点「记忆库」标签页 | 本次任务产生的 N 条记忆：每条显示 chunk_id / 层(D·C·R) / 密级 / **密文** / 溯源链 / Merkle 哈希 |

> 第 6–9 步是「查阅/采用」的完整落点：**采用 = 采信它、污染进血缘链；查阅 = 参考它、写回被 DENY。** 水位只是症状，写回那一下才是本质。
> 第 15 步是「存到哪」的落点：任务跑完，记忆加密落库（SQLite 密文 + CKKS 向量 + Merkle 哈希），每条能溯源。
